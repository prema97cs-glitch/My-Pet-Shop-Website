🐾 My Pet Shop Website

Welcome to my Pet Shop Website! 🐶🐾  
This website is designed to help users explore and buy different dog breeds easily.

---

 🌟 About the Website

This is a simple and user-friendly pet shop website where you can:

- 🐕 Browse Indian & International dog breeds  
- 💰 Check price ranges for each breed  
- 💉 View vaccination details  
- 🍗 Get recommended food information  
- ❤️ Learn about dog traits (guard dog, friendly, active, etc.)
